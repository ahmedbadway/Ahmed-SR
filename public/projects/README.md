# Project cover screenshots

Drop one screenshot per project here, named exactly as below (WebP, ~16:10,
e.g. 1600×1000, under 200KB). The cards pick them up automatically; until a
file exists, the card shows its gradient + monogram fallback.

Run `node scripts/optimizeImages.mjs` after adding a new PNG/JPEG here to
convert it to a size-budgeted WebP automatically.
